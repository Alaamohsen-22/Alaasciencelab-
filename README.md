# مختبر اكتشف | مختبر الكيمياء الافتراضي

React + TypeScript + Vite + SVG. الصف الثامن الأساسي، المنهاج الفلسطيني، الوحدة الخامسة «حياتنا كيمياء» فقط.

## التشغيل

```sh
npm ci
npm run dev
npm test
npm run build
```

## المصدر ونطاق التنفيذ

كتاب العلوم والحياة، الجزء الثاني، الطبعة الثالثة 2020، الملف الذي أرفقه المستخدم. أرقام الصفحات التالية هي المطبوعة (صفحة PDF = المطبوعة + 4).

- ص4–7: الروابط الأيونية LiF وMgCl₂، التساهمية H₂ وO₂ وCH₄؛ اختيار النموذج، انتقال الإلكترونات تدريجيًا، عرض الشحنات والتوزيع، مشاركة الأزواج.
- ص8–10: تجربة Zn/HCl بكمية الحمض المذكورة 20 مل، ترتيب الأدوات، محاكاة غاز الهيدروجين وانتفاخ البالون؛ موازنة أربع معادلات وعد الذرات. الزمن والحجم توضيحيان بسبب غياب تركيز الحمض وكتلة الخارصين.
- ص11–14: دلالات التفاعل ملخصة في إنفوجرافيك تفاعلي؛ الأنشطة الإضافية لهذه الصفحات ليست كلها محاكاة منفصلة.
- ص15–22: قرئ الدرس كاملًا. محطات دوار الشمس لليمون وHCl والماء والرماد وNaOH؛ توصيل HCl وNaOH؛ Mg/HCl واختبار الغاز؛ التعادل والتبخير؛ الكبريت والأكسجين ودوار الشمس المبلل؛ تصنيف أمثلة الجداول الستة عشر.
- جداول الأمثلة: الحموض HCl/H₂SO₄/HNO₃/CH₃COOH، القواعد NaOH/KOH/Mg(OH)₂، الأملاح NaCl/NaHCO₃/MgSO₄/CuSO₄، الأكاسيد PbO₂/ZnO/CO₂/SiO₂، وCaO من تمهيد الدرس.

## حدود علمية معلنة داخل الواجهة

1. الرسوم ثنائية الأبعاد وليست هندسة جزيئية ثلاثية الأبعاد؛ الأملاح تمثل وحدات صيغة داخل شبكة أيونية. أزواج التساهمية تمثل المشاركة ولا تزيد العدد الكلي للإلكترونات.
2. تجربة التعادل تستخدم مقادير نموذج مبسط معلنة بدل ادعاء إعادة إنتاج تحضير الكتاب. يحسب المتفاعل الفائض والملح وفق HCl + NaOH. دوار الشمس لا يحدد التعادل بدقة؛ اللون الزهري يدل على فائض حمض. يتم التبخير في النموذج عند التعادل.
3. انصهار الكبريت تغير فيزيائي، وSO₂ ينتج من الاحتراق في الأكسجين. لا يعمم ذوبان الأكاسيد على SiO₂ ولا تعادل محاليل جميع الأملاح.
4. تجربة التوصيل وصفية: لا يحسب تيارًا أو شدة إضاءة؛ يوضح إكمال الدارة وغمس الأقطاب.
5. لا تذوق أو لمس أو تجربة كيميائية حقيقية مقترحة. جميع اختبارات اللهب رقمية.

## الصورة والصوت والبيانات

لم يتوفر ملف محلي للصورة المعروضة في المحادثة؛ موضع الصورة جاهز في الغلاف وبطاقة التعزيز. يمكن اختيار الصورة الأصلية من تذييل الموقع، دون تعديل. تخزن على متصفح ذلك الجهاز فقط ولا تنتقل إلى الزوار الآخرين. لدمجها مع النسخة المنشورة يجب توفير ملف الصورة ثم إضافته إلى public وربطه داخل التطبيق.

الصوت يستخدم Web Speech API المجاني. يحاول اختيار صوت عربي أنثوي معروف؛ توفره وجودته يعتمدان على المتصفح والجهاز. النص ظاهر دون الصوت. لا يوجد صوت مسجل ولا خدمة مدفوعة. الخط من Google Fonts مع بديل Tahoma محلي.

الملاحظات والصورة والنجوم تحفظ في localStorage، ويمكن تنزيل الملاحظات. لا توجد حسابات أو قاعدة بيانات. النجوم ستة: إنجاز عملي واختبار لكل درس، ولا تتكرر لنفس الإنجاز.

## GitHub Pages

ملف `.github/workflows/deploy.yml` جاهز؛ بعد رفع المشروع إلى مستودع المستخدم على الفرع main اختر Settings → Pages → Source: GitHub Actions. البناء يستخدم مسارات نسبية ملائمة لمستودعات Pages. المستودع المستهدف: https://github.com/Alaamohsen-22/Alaasciencelab- . رفع المصدر لا يعني تفعيل GitHub Pages؛ يلزم اختيار GitHub Actions كمصدر النشر في إعدادات المستودع.

## التحقق

اختبارات منطق المحاكاة: انتقال LiF، انتقال MgCl₂ مع حفظ الإلكترونات والشحنة، أزواج التساهمية، حفظ الذرات في المعادلات، والتعادل والمتفاعل الفائض. حالة البناء والاختبارات النهائية يسجلها المنفذ بعد التنفيذ. لا تُعد هذه الاختبارات بديلًا لاختبار الاستخدام المرئي.

التحقق المنفذ: نجح `npm run build`، واجتازت اختبارات المنطق الخمسة `npm test`. لم يتوفر مسار مدعوم للتحكم بالمتصفح، لذلك لم يُنفذ اختبار مرئي أو اختبار نقرات على الموبايل واللابتوب. يحتاج ذلك إلى مراجعة قبل اعتماد النسخة للطلاب.
